Unggah Berkas Kontak

Petunjuk Import Kontak

1
Unduh Format Template
Gunakan format kolom resmi agar nama, nomor telepon, dan email tidak tertukar.
2
Format Nomor Telepon
Gunakan awalan 08 atau 62 (contoh: 081234567890) tanpa spasi atau tanda hubung (-).
3
Pencegahan Duplikasi
Jika nomor telepon sudah terdaftar, sistem akan memperbarui data pelanggan tersebut.
